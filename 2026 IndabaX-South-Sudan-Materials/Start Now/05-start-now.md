# Start Now: Building AI and ML Skills as a Student

Students do not need to wait for a degree, a powerful laptop or a famous dataset to start building AI skills. That was the message from Chol Daniel Deng Dau, a software engineer working in ML and AI, in his session "Start Now: Building AI and ML Skills as a Student" at IndabaX South Sudan 2026, held at Scenius Hub in Juba.

His talk was practical: a clear learning order, a real project to learn from, free resources, and a push to start this month.

## From a messy spreadsheet to AI models

Chol's own path began with something ordinary. As a Mastercard Foundation Scholar studying Software Engineering at the African Leadership University (ALU) in Kigali, his interest in data started when he cleaned a messy student attendance dataset and built a Power BI dashboard from it.

From there, he learned by building — through hackathons, school projects and networking. Today he is Technical Project Lead at Businesslab IT Services and an AWS Certified Solutions Architect – Associate.

## Five steps, in order

Chol's core advice was to follow a sequence rather than jump straight to the most exciting topic:

1.  **Programming (Python)** — write small programs every day.

2.  **Data handling** — pandas, cleaning messy data and basic SQL.

3.  **Maths and statistics** — learn it just in time, as your models demand it.

4.  **Machine learning fundamentals** — use scikit-learn to train, test and evaluate models.

5.  **Deep learning** — only once the basics are solid.

The point is that strong foundations make the advanced material far easier to absorb.

## Learn by building a problem you can see

Instead of practising on famous datasets, Chol urged students to pick a problem they can see around them. He shared his own example.

His team noticed that medical information is hard to access for people who don't speak English, especially in rural communities. In 48 hours, the team of four built Unesis AI — NLP pipelines that translate medical information into local African languages.

The project won 1st Place at the ALU × Meta Hackathon 2024, recognised for social impact and technical innovation.

## Free tools and courses

Cost should not be a barrier. Chol pointed participants to free or low-cost resources:

- Machine Learning Specialization by Andrew Ng on Coursera, with a free audit option

- Google Machine Learning Crash Course, with interactive exercises

- Kaggle Intro to ML and Kaggle Learn, short hands-on lessons on real data

- freeCodeCamp's Machine Learning with Python full video course

- DataCamp's Machine Learning Scientist and Machine Learning Engineer tracks

For students without a strong laptop, Google Colab offers free notebooks that run in the browser.

## Show your work, then start

Chol closed with three things every student should build alongside their skills:

- **Portfolio** — a GitHub profile with two or three finished projects, plus a simple personal site.

- **Communities** — Zindi competitions, Kaggle and the AWS Cloud Club.

- **Pathways** — scholarships, internships and research placements.

His final challenge was simple: pick one problem, build one project, and start this month.
